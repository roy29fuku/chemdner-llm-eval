# Experiment 008: BioBERT Fine-tuning for CHEMDNER

## 概要

BioBERTをCHEMDNERデータセットでファインチューニングし、化学物質エンティティ認識のSOTA（F1=94.30%）に近づける。

## 背景

| 実験 | 手法 | F1 |
|------|------|-----|
| exp001 | GPT-4.1 few-shot (4例) | 68.73% |
| exp001 | GPT-5.2 few-shot (4例) | 69.80% |
| exp006b | GPT-5.2 MRC+verify | 75.96% |
| **exp008** | **BioBERT fine-tuning** | **TBD** |
| SOTA | CRF/BiLSTM-CRF | 94.30% |

LLMによるゼロショット・few-shotアプローチは最大でもF1=76%程度に留まった。
ドメイン特化型のファインチューニングでどこまで改善できるかを検証する。

## 実験設定

### モデル

- **Base model**: `dmis-lab/biobert-v1.1`
- **Task**: Token Classification (NER)
- **Labels**: O, B-CHEMICAL, I-CHEMICAL

### ハイパーパラメータ

| パラメータ | 値 |
|------------|-----|
| learning_rate | 2e-5 |
| batch_size | 16 |
| epochs | 5 |
| max_seq_length | 256 |
| warmup_ratio | 0.1 |
| weight_decay | 0.01 |
| fp16 | True |

### データ

- **Train**: training.ner.ssplit.token4.BIO
- **Dev**: development.ner.ssplit.token4.BIO
- **Test**: evaluation.ner.ssplit.token4.BIO

### インフラ

- **Platform**: GCP Compute Engine
- **Machine**: a2-standard-4 (1x NVIDIA A100)
- **Image**: Deep Learning VM (PyTorch 2.7, CUDA 12.8)

## 実行手順

```bash
# 1. GCPプロジェクト作成（初回のみ）
gcloud projects create chemdner-biobert-training

# 2. 課金アカウントをリンク（Consoleから手動）
# https://console.cloud.google.com/billing/linkedaccount?project=chemdner-biobert-training

# 3. APIを有効化
gcloud services enable compute.googleapis.com --project=chemdner-biobert-training

# 4. Terraformでインスタンス作成
cd infrastructure
cp terraform.tfvars.example terraform.tfvars
# terraform.tfvarsを編集
terraform init
terraform apply

# 5. セットアップ（コード・データ転送）
./scripts/setup_training.sh

# 6. 学習実行
./scripts/run_training.sh

# 7. 結果ダウンロード
./scripts/download_results.sh

# 8. 評価
docker compose run --rm chemdner python src/evaluate.py --input-dir outputs/exp008_biobert

# 9. インフラ削除
cd infrastructure && terraform destroy
```

## 結果

### 学習曲線

- Train loss: 0.025
- Epoch: 5
- Total steps: 9630
- 学習時間: 約25分

### 評価結果

| Metric | Dev | Test |
|--------|-----|------|
| Precision | 88.66% | **90.85%** |
| Recall | 91.53% | **91.35%** |
| F1 | 90.08% | **91.10%** |
| Accuracy | 99.18% | 99.29% |

### 比較

| 手法 | F1 | 差分 |
|------|-----|------|
| GPT-5.2 MRC+verify | 75.96% | baseline |
| **BioBERT fine-tuned** | **91.10%** | **+15.14pt** |
| SOTA (CRF) | 94.30% | -3.20pt |

## 考察

1. **大幅な改善**: GPT-5.2のfew-shot/MRCアプローチ（F1=75.96%）から+15pt以上の改善
2. **SOTAに近い**: CRF/BiLSTM-CRFのSOTA（F1=94.30%）まであと3pt
3. **高速・低コスト**: 25分、$2以下で学習完了
4. **Precision/Recallバランス**: 両方90%超えでバランスが取れている
