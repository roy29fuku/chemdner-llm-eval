# Experiment 001: LLMによるCHEMDNER化学物質名抽出

## 概要

- **日時**: 2026-01-25 10:33〜11:31（約1時間）
- **目的**: 現代のLLM（GPT-4.1, GPT-5.2）でCHEMDNERタスクの精度を検証
- **データセット**: CHEMDNER evaluation set (2,646 documents)
- **最終結果**: GPT-5.2 F1=71.82%（2013年最高値87.39%との差: 約15pt）

## 精度改善の経緯

### サマリー

| Version | 手法 | GPT-4.1 F1 | GPT-5.2 F1 | 改善幅 |
|---------|------|------------|------------|--------|
| v1 | Zero-shot | 0.4633 | 0.5689 | - |
| v2 | Few-shot (4例) | 0.6978 | 0.7182 | **+14.9pt** |

### 詳細な変遷

```
Zero-shot (v1)
├── GPT-4.1: P=0.33, R=0.77, F1=0.46
└── GPT-5.2: P=0.45, R=0.78, F1=0.57
    │
    │ [改善施策]
    │ ・Few-shot例を4つ追加
    │ ・CHEMDNERガイドラインに基づくプロンプト詳細化
    │ ・化学物質/タンパク質の境界を明示
    ↓
Few-shot (v2)
├── GPT-4.1: P=0.69, R=0.71, F1=0.70 (+0.24)
└── GPT-5.2: P=0.73, R=0.71, F1=0.72 (+0.15)
```

## 改善効果の分析

### Precision vs Recall の変化

| Model | Version | Precision | Recall | 変化 |
|-------|---------|-----------|--------|------|
| GPT-4.1 | v1 → v2 | 0.33 → 0.69 | 0.77 → 0.71 | P大幅改善、R微減 |
| GPT-5.2 | v1 → v2 | 0.45 → 0.73 | 0.78 → 0.71 | P大幅改善、R微減 |

**考察:**
- Few-shotにより「何を抽出すべきか」の境界が明確になり、過剰抽出が減少
- Recallの微減は、境界ケースで保守的になった影響
- Precisionの大幅改善がF1向上に寄与

### False Positive削減

| Model | v1 FP | v2 FP | 削減数 | 削減率 |
|-------|-------|-------|--------|--------|
| GPT-4.1 | 22,829 | 4,746 | 18,083 | **79%減** |
| GPT-5.2 | 14,249 | 3,860 | 10,389 | **73%減** |

## 技術的な工夫

### 1. 並列処理の実装

```python
async def process_batch(samples, model, semaphore):
    async with semaphore:
        return await call_api(sample, model)

semaphore = asyncio.Semaphore(50)  # Tier 5推奨値
```

- 逐次処理: 推定2.5時間 → 並列50: 約3分
- **50倍の高速化**

### 2. コスト見積もり機能

```
============================================================

============================================================
Number of samples: 2646
Estimated input tokens:  2,865,707
Estimated output tokens: 529,200

TOTAL ESTIMATED COST: $22.3888
============================================================
```

- tiktokenによる事前トークン数推定
- 実行前に確認プロンプト（-yでスキップ可能）

### 3. データリーク防止

```
training set (Few-shot例の取得元)
    ↓
evaluation set (推論・評価対象) ← データリークなし
```
