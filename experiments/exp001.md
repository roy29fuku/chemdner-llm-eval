# Experiment 001: Few-shot (4例) による化学物質名抽出

## 概要

- **日時**: 2026-01-25
- **目的**: Few-shot prompting によるCHEMDNERタスクのベースライン確立
- **データセット**: CHEMDNER evaluation set (2,646 documents)

## 実験設定

### モデル
- GPT-4.1 (`gpt-4.1`)
- GPT-5.2 (`gpt-5.2`)

### プロンプト設計
- Few-shot: training setから4例を選択
- 出力形式: JSON array
- 並列度: 50 requests/model

### Few-shot例の選択基準
1. 複数の化学物質を含む（2-5個程度）
2. 多様なカテゴリ（TRIVIAL, SYSTEMATIC, ABBREVIATION等）
3. 文脈が明確で誤解しにくい

## 結果

| Model   | Micro-P | Micro-R | Micro-F1 | Macro-F1 |   TP |   FP |   FN |
|---------|---------|---------|----------|----------|------|------|------|
| gpt-4.1 |  0.6885 |  0.7072 |   0.6978 |   0.6248 | 10492 | 4746 | 4343 |
| gpt-5.2 |  0.7307 |  0.7060 |   0.7182 |   0.6416 | 10474 | 3860 | 4361 |

### 参考: 2013年CHEMDNER Challenge最高成績
- F1 = 87.39% (CRFベースの専門モデル)

## 考察

### GPT-5.2 vs GPT-4.1
- GPT-5.2がMicro-F1で約2ポイント上回る（71.82% vs 69.78%）
- GPT-5.2はPrecisionが高い（73.07%）→ 誤検出が少ない
- Recallはほぼ同等（70.60% vs 70.72%）

### 2013年最高値との差
- 約15ポイントの差（71.82% vs 87.39%）
- 汎用LLMの限界 vs 専門タスク特化モデル

### 5件テストとの乖離
- 5件テストではGPT-5.2 F1=0.85だったが、全件では0.72に低下
- 少数サンプルでの評価は楽観的になりやすい

## 成果物

- 予測結果: `outputs/exp001_fewshot4_evaluation/predictions_gpt-{model}.json`
- 評価スクリプト: `src/evaluate.py`

## 次のステップ候補

1. **エラー分析**: False Positive/False Negativeの傾向分析
2. **Few-shot例の増加**: 8例、16例での効果検証
3. **プロンプト改善**: カテゴリ定義の明確化、boundary caseの例示
4. **他モデル**: Claude, Gemini等との比較

## 実行コマンド

```bash
# 推論
docker compose run --rm chemdner python src/inference.py \
  --parallel 50 \
  --models gpt-4.1 gpt-5.2 \
  --output-dir outputs/exp001_fewshot4_evaluation \
  -y

# 評価
docker compose run --rm chemdner python src/evaluate.py \
  --input-dir outputs/exp001_fewshot4_evaluation \
  --pattern '*.json'
```
