# Experiment 007: GLiNER-BioMed

## 概要

- **日時**: 2026-01-25
- **目的**: LLM以外の選択肢としてGLiNER-BioMedを評価
- **結果**: **F1 = 0.43** - 期待を大きく下回る結果

## 背景

### GLiNER-BioMedとは

- [GLiNER-BioMed](https://huggingface.co/Ihor/gliner-biomed-base-v1.0): ゼロショットバイオメディカルNERモデル
- 追加学習なしで任意のエンティティタイプを抽出可能
- 参考: [BioASQ 2025での実績](https://arxiv.org/html/2510.08588) - 辞書後処理で0.79→0.83

### 期待値

alternatives.mdでの見積もり:
- 期待F1: 79-83%（辞書後処理込み）
- 実装難易度: 低（Hugging Faceからダウンロード）

## 実験設定

### モデル

```python
from gliner import GLiNER
model = GLiNER.from_pretrained("Ihor/gliner-biomed-base-v1.0")
```

### エンティティラベル

```python
CHEMICAL_LABELS = ["chemical", "chemical compound", "drug", "molecule"]
```

### 閾値

- 0.3（高Recall設定）
- 0.5（バランス設定）

## エラー分析

### False Positives（過剰抽出）の例

GLiNER-BioMedは化学物質以外も大量に抽出している:

1. **タンパク質・酵素**:
   - `cyp3a4`, `enos` (endothelial nitric oxide synthase)
   - `hepatic transporters`, `secretory and absorptive transporters`

2. **サイトカイン**:
   - `interleukin 1β`, `interleukin 6`, `tumor necrosis factor α`
   - `inflammatory cytokines`

3. **遺伝子関連**:
   - `vntr`, `glu298asp`, `intron 4`

4. **一般的なバイオ用語**:
   - `cotton dust`, `garlic phytochemicals`

### False Negatives（見逃し）の例

1. **化学式・略語**:
   - `NO` (nitric oxide), `Mg`, `ADP`

2. **複雑な化学名**:
   - `(25)MgPMC16`

3. **一般的な化学物質名**:
   - `monocarboxylate`, `docosahexaenoic acids`

## 考察

### 期待を下回った理由

1. **モデルの特性**
   - GLiNER-BioMedは「バイオメディカル一般」のNERモデル
   - 化学物質とタンパク質・遺伝子を区別する能力が低い
   - CHEMDNERの境界ケース（タンパク質を除外）に対応できない

2. **ゼロショットの限界**
   - "chemical"というラベルだけでは、CHEMDNERの定義に合わない
   - CHEMDNERは「化学構造が決定可能なもの」という厳密な定義
   - タンパク質名も広義では「化学物質」と解釈可能

3. **参考文献との乖離**
   - BioASQ 2025での0.79-0.83という数値は、異なるタスク（一般的なバイオエンティティ抽出）の可能性
   - CHEMDNERのような厳密な化学物質抽出には不向き

### GPT-5.2との比較

| 観点 | GPT-5.2 | GLiNER-BioMed |
|------|---------|---------------|
| 境界ケース判断 | Few-shotで学習可能 | ゼロショットでは困難 |
| タンパク質除外 | 明示的に指示可能 | 区別できない |
| 化学式認識 | 良好 | 見逃しが多い |
| 精度 | F1=0.76 | F1=0.43 |

## 結論

**GLiNER-BioMedはCHEMDNER化学物質NERには適さない。**

- 精度: GPT-5.2より**33pt低い**
- 主な問題: タンパク質・遺伝子と化学物質を区別できない
- 追加学習なしでは改善困難

### 次のステップ

1. **BioBERT/PubMedBERTのファインチューニング**
   - CHEMDNERデータセットでの学習が必要
   - 期待F1: 89-93%

2. **辞書ベース後処理の検討**
   - PubChem/ChEBI辞書との照合
   - ただしGLiNER単体のFPが多すぎて効果限定的

3. **GPT-5.2のさらなる改善**
   - 現状F1=0.76が最高値
   - 辞書との組み合わせでさらなる改善の可能性
