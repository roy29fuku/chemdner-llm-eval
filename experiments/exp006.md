# Experiment 006: MRC (Machine Reading Comprehension) 形式プロンプト

## 概要

- **日時**: 2026-01-25 12:11〜12:17
- **目的**: SOTA手法（BioBERT-MRC）の原理をLLMに適用し、精度向上を検証
- **結果**: **MRC + Self-verify で F1 = 0.7596（+4.14pt）** - 新たな最高値

## 背景

### MRC手法がSOTAを達成している理由
- [BioBERT-MRC](https://ar5iv.labs.arxiv.org/html/2009.01560): F1=92.92%
- [MatSciBERT-MRC](https://jcheminf.biomedcentral.com/articles/10.1186/s13321-024-00874-5): F1=94.30%

NERをシーケンスラベリングではなく、**質問応答問題として定式化**することで精度向上。

## 実験設定

### MRCプロンプトの設計

```
## Question
What are all the chemical entity mentions in this text?
A chemical entity is any mention whose chemical structure can be determined or inferred.

## Types of chemical entities to find:
1. TRIVIAL: Common/trivial names (aspirin, caffeine, morphine)
2. SYSTEMATIC: IUPAC names (2-acetoxybenzoic acid)
3. ABBREVIATION: Chemical abbreviations (ATP, NAD+, NO)
4. FORMULA: Molecular formulas (H2O, NaCl)
5. FAMILY: Chemical families (polycyclic aromatic hydrocarbons)
```

### 比較対象
| 設定 | 説明 |
|------|------|
| Exp006a | MRC単独 |
| Exp006b | MRC + Self-verify |

## 結果

| 設定 | Micro-P | Micro-R | Micro-F1 | TP | FP | FN |
|------|---------|---------|----------|------|------|------|
| Exp001 (ベースライン) | 0.7307 | 0.7060 | 0.7182 | 10474 | 3860 | 4361 |
| Exp005 (Self-verify) | 0.8077 | 0.6917 | 0.7452 | 10261 | 2443 | 4574 |
| Exp006a (MRC) | 0.6091 | 0.7841 | 0.6856 | 11632 | 7465 | 3203 |
| **Exp006b (MRC + verify)** | **0.7559** | **0.7633** | **0.7596** | 11323 | 3656 | 3512 |

### 差分（vs ベースライン）
- **Exp006a (MRC単独)**: F1 -3.26pt
  - Recall +7.81pt（大幅向上）
  - Precision -12.16pt（大幅低下）
  - FP 93%増（過剰抽出）

- **Exp006b (MRC + verify)**: F1 **+4.14pt**
  - Recall +5.73pt（向上）
  - Precision +2.52pt（向上）
  - **バランスの取れた改善**

## 考察

### MRC単独が効果的でなかった理由

1. **過剰抽出の傾向**
   - 質問形式が「化学物質を見つけよ」と強調しすぎ
   - 曖昧なケースも抽出する傾向（FPが93%増）

2. **LLMの特性**
   - 生成モデルは「答えを出したい」傾向が強い
   - 質問されると何か答えようとする

### MRC + Self-verifyが効果的だった理由

1. **相補的な効果**
   - MRC: Recallを向上（見逃しを減らす）
   - Self-verify: Precisionを向上（過剰抽出を減らす）

2. **タスクの分離**
   - 第1段階: 広く候補を抽出（MRCの強み）
   - 第2段階: 厳密に検証（Self-verifyの強み）

3. **バランスの改善**
   - Self-verify単独: P=0.81, R=0.69（Recall低い）
   - MRC + verify: P=0.76, R=0.76（バランス良い）

### 結論

**MRC + Self-verifyの組み合わせが最も効果的。**

- MRCでRecallを確保し、Self-verifyでPrecisionを維持
- 単独よりも組み合わせが効果的
- F1=75.96%を達成（SOTAとの差: -18.34pt）

## 実行コマンド

```bash
# MRC単独
docker compose run --rm chemdner python src/inference.py \
  --parallel 50 \
  --models gpt-5.2 \
  --mrc \
  --output-dir outputs/exp006_mrc \
  -y

# MRC + Self-verify
docker compose run --rm chemdner python src/inference.py \
  --parallel 50 \
  --models gpt-5.2 \
  --mrc --verify \
  --output-dir outputs/exp006b_mrc_verify \
  -y

# 評価
docker compose run --rm chemdner python src/evaluate.py \
  --input-dir outputs/exp006b_mrc_verify
```
