# v1（2026-01 の探索的な実験）

2026-01-25 に行った最初の実験のコードと記録。BPPB の Note（BSJ-2026038）の初回投稿（2026-06-30）は、この実験の値（LLM 75.96%・BioBERT 91.10%）を使っていた。

**この 2 つの値は比較に使えない。** 査読への対応で確かめたところ、次のことが分かった。

- F1 の定義が違う。LLM（`src/evaluate.py`）は 10 文ずつの疑似文書ごとに化学物質名の集合を小文字で照合し、BioBERT（`src/biobert/train.py`）は文ごとの言及スパンを seqeval で照合している
- LLM 側は 7 通りのプロンプトをすべて評価データで採点し、最良の値を報告した
- a（LLM に直接解かせる）と b（コードを書かせる）でモデルが違う（GPT-5.2 と、Claude Opus 4.5 を土台にした Claude Code）
- BioBERT は 1 回の学習の値

このため、条件をそろえた比較（v2）を repo のルートで作り直している。v1 は記録として、ここに当時のまま残す。
