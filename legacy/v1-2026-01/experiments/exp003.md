# Experiment 003: Chain-of-Thought (CoT) Prompting

## 概要

- **日時**: 2026-01-25 11:50〜12:00
- **目的**: Chain-of-Thoughtプロンプティングによる精度向上を検証
- **仮説**: 推論過程を明示的にさせることで、境界ケースの判断精度が向上する

## 実験設定

### 比較対象
| 項目 | Exp001 (ベースライン) | Exp003 |
|------|----------------------|--------|
| モデル | GPT-5.2 | GPT-5.2 |
| API | Chat Completions | Chat Completions |
| プロンプト | Few-shot (4例) | Few-shot (4例) + CoT |

### CoTプロンプトの追加内容

```
## Chain-of-Thought Process
Before outputting the final answer, think step by step:
1. Scan the text and identify ALL potential chemical-related terms
2. For EACH candidate, ask: "Can I determine or infer its chemical structure?"
3. Check if it's a protein, enzyme, gene, or transporter (if yes, EXCLUDE)
4. Verify the exact text span to extract

## Output Format
First, show your reasoning in <thinking> tags.
Then output the JSON array.
```

## 結果

| API | Micro-P | Micro-R | Micro-F1 | TP | FP | FN |
|-----|---------|---------|----------|------|------|------|
| Few-shot (Exp001) | 0.7307 | 0.7060 | 0.7182 | 10474 | 3860 | 4361 |
| **Few-shot + CoT** | 0.7703 | 0.6401 | 0.6992 | 9496 | 2831 | 5339 |

### 差分
- **Micro-F1**: **-1.90pt**（CoTで悪化）
- **Precision**: +3.96pt（大幅改善）
- **Recall**: -6.59pt（大幅悪化）

### TP/FP/FNの変化
- **TP**: 10474 → 9496（-978件、9.3%減）
- **FP**: 3860 → 2831（-1029件、26.7%減）
- **FN**: 4361 → 5339（+978件、22.4%増）

## 考察

### なぜRecallが低下したか

1. **過度に保守的な判断**
   - CoTで「化学物質か否か」を明示的に考えさせることで、曖昧なケースを除外する傾向が強まった
   - 「Can I determine or infer its chemical structure?」という問いが厳しすぎた可能性

2. **思考過程でのエラー伝播**
   - 推論ステップで一度「これは化学物質ではない」と判断すると、その判断が最終出力に反映される
   - 直感的な認識より、論理的推論が誤りを含む場合がある

3. **NERタスクとCoTの相性**
   - NERは「パターン認識」が中心のタスク
   - 論理的推論を強制することで、かえってパターン認識能力が阻害された可能性

### Precisionが向上した理由

- False Positiveが26.7%減少
- 「除外すべきもの」の判断は改善
- しかし「含めるべきもの」も除外してしまった

### 結論

**CHEMDNERタスクにおいて、Chain-of-Thoughtプロンプティングは逆効果。**

- Precisionは向上するが、Recallの大幅な低下がそれを上回る
- NERのような認識タスクには、直感的なパターンマッチングの方が適している
- CoTは推論タスク（数学、論理問題）に向いており、認識タスクには不向き

CoTでの改善が見られなかったため、別のアプローチを検討：

2. **Self-verification（2段階処理）**: 抽出後に検証ステップを追加

### 教訓

- 推論を強制するCoTは、認識タスクには不向き
- NERはパターン認識が中心であり、「考えさせる」より「例を見せる」方が効果的
- Precision/Recallのトレードオフに注意
